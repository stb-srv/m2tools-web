01

📜 Quest Grundlagen

Gib deinem Quest einen Namen und erstelle die States (Zustände) die dein Quest durchlaufen soll.

💡 Was sind States?

Ein Quest besteht aus mehreren States (Zuständen). Der Spieler wechselt zwischen States basierend auf seinen Aktionen. Jeder Quest beginnt immer im State start.

Nutze nur Buchstaben, Zahlen und Unterstriche.

📋 States verwalten

02

⚡ Trigger wählen

Wähle aus, welches Event den Quest-Code in diesem State auslöst.

💡 Was ist ein Trigger?

Ein Trigger bestimmt wann der Quest-Code ausgeführt wird. Z.B. wenn ein Spieler einen NPC anklickt, ein Monster tötet oder sich einloggt.

State: start
03

🔍 Bedingungen Optional

Setze Voraussetzungen die erfüllt sein müssen, damit der Quest-Code ausgeführt wird.

💡 Wann brauche ich Bedingungen?

Bedingungen prüfen z.B. ob der Spieler ein bestimmtes Level hat, genug Gold besitzt oder ein Item im Inventar hat. Ohne Bedingungen wird der Quest immer ausgeführt.

State: start
04

💬 Dialog erstellen Optional

Schreibe den Text, den der NPC dem Spieler sagt.

💡 Wie funktionieren Dialoge?

NPC-Dialoge erscheinen als Textfenster im Spiel. Der Titel wird oben angezeigt, die Zeilen sind der Inhalt. Jede Zeile wird separat als say() ausgegeben.

State: start
05

⚙️ Aktionen festlegen

Bestimme, was passiert wenn der Quest ausgelöst wird.

💡 Was sind Aktionen?

Aktionen sind die Dinge die passieren: Items geben, Gold verteilen, den Spieler teleportieren, den Quest-State wechseln, usw.

State: start

06

❓ Verzweigung Optional

Gib dem Spieler Auswahlmöglichkeiten mit verschiedenen Ergebnissen.

💡 Wie funktioniert select()?

Mit select() zeigst du dem Spieler mehrere Optionen. Je nach Wahl werden unterschiedliche Aktionen ausgeführt – z.B. quest annehmen oder ablehnen.

State: start
